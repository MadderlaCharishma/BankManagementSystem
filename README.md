📌 Project Overview

This repository contains two banking management system projects developed using different technologies:

🐍 Python-based Banking System (Flask + MySQL + Web UI)
☕ Java-based Banking System (Swing + JDBC + MySQL)

Both projects simulate basic banking operations like user registration, login, deposits, transactions, and account management.

🧩 Projects Included
🐍 1. Python Banking System

A web-based banking application built using Flask framework.

✨ Features:
User Registration & Login
Secure Authentication
Deposit & Balance Management
Transaction History
Simple Web Dashboard
🛠️ Tech Stack:
Python
Flask
MySQL
HTML, CSS, JavaScript
☕ 2. Java Banking System

A desktop-based banking application using Java Swing.

✨ Features:
GUI-based Login System
Account Creation
Deposit & Withdraw
Transaction Records
User-friendly Desktop Interface
🛠️ Tech Stack:
Java
Swing (GUI)
JDBC
MySQL
